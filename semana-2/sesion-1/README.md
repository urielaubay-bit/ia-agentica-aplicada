# Semana 2 · Sesión 1 · Streaming (Next.js)

**30 min teoría + 90 min práctica.** Tu agente en una web que transmite en streaming.

## Instalar y correr
```bash
cp .env.example .env.local   # pon tu ANTHROPIC_API_KEY
npm install
npm run dev                  # http://localhost:3000
```

Escribe cualquier cosa: la respuesta aparece incremental (streaming). En la Sesión 2 le agregamos UI generativa (componentes).
