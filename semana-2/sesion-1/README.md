# Semana 2 · Sesión 1 · Streaming (Next.js)

**30 min teoría + 90 min práctica.** El copiloto de NeuronBank en una web que transmite en streaming.

## Instalar y correr
```bash
npm install
npm run dev                  # http://localhost:3000
```

Pregunta por una cuenta (ej. "¿cuál es el saldo de CU-1001?"): la respuesta aparece incremental (streaming). En la Sesión 2 le agregamos UI generativa (componentes).
