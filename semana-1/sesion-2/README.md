# Semana 1 · Sesión 2 · Structured output + tu dominio

**30 min teoría + 90 min práctica.** Obtienes JSON validado con `generateObject`, y arrancas TU proyecto.

## Instalar
```bash
cp .env.example .env
npm install
```

## Pasos
- `npx tsx --env-file=.env paso4.ts` — reporte ejecutivo validado (5 claves).
- `tu-dominio.ts` — plantilla: define TU tool + TU schema y corre tu agente baseline.

## Tu proyecto
Elige tu dominio (soporte, ventas, salud, legal, lo que vendas) y adáptalo en `tu-dominio.ts`. Este es el proyecto que evoluciona 5 semanas.
